KI-Zugänge

Mit einem Zugang bedient ein KI-Assistent wie Claude Nestwerk in deinem Namen: Termine, ToDos, Haushaltsplan, Kontakte und Benachrichtigungen. Er sieht und darf genau das, was du darfst. Löschen kann er nichts.

Mit deinem Nestwerk-Login verbinden

Am einfachsten: Du gibst dem Assistenten nur die Adresse https://nestwerk.example.org/mcp. Beim ersten Zugriff öffnet sich ein Browserfenster, du meldest dich wie gewohnt an und stimmst zu. Ein Token musst du nicht kopieren.

Claude (claude.ai, Desktop-App, Smartphone)

  1. In Claude Einstellungen → Konnektoren → Benutzerdefinierten Konnektor hinzufügen öffnen.
  2. Name Nestwerk und die Adresse oben eintragen, dann Verbinden.
  3. Im Browser bei Nestwerk anmelden und Zustimmen wählen.

Dafür muss Nestwerk über HTTPS aus dem Internet erreichbar sein, denn claude.ai verbindet sich von den Servern von Anthropic aus.

Claude Code

claude mcp add …

Danach in Claude Code /mcp eingeben, nestwerk wählen und Authenticate – der Browser öffnet die Anmeldung.
